# K230 无线预览

## 扫码与避障同时运行

运行 `避障跑图.py`，同时提供扫码、避障串口和无线网页。七个文件及接线见 [AVOIDANCE_TEST.md](../../AVOIDANCE_TEST.md)。Wi-Fi 参数在 `wifi_config.py`，成功联网后终端打印 `K230 preview: http://<实际IP>:8080/`。网页显示持续检测的最新帧、底部行、距图底像素量及标定是否超范围；运行期间禁止调参。不要同时启动其他摄像头入口。

## 独立黑块测试

用于亚博 K230 CanMV 单独测试：浏览器看带检测框的画面、修改黑色 LAB 阈值和最低像素数。不会初始化STM32串口，不会控制车辆。

## 第一次运行

1. 在本目录将 `wifi_config.example.py` 复制为 `wifi_config.py`，编辑其中的 `WIFI_SSID` 和 `WIFI_PASSWORD`。该本地配置已被 Git 忽略，账号密码不提交到仓库。直接使用源文件，不打包 ZIP。先使用2.4GHz Wi-Fi或手机热点。
2. 电脑连接同一个Wi-Fi。热点或路由器需允许设备间通信；访客网络/客户端隔离会使电脑无法访问K230。
3. 用USB连接CanMV IDE，将 `避障无线预览.py`、`obstacle_detection.py`、`obstacle_web.py`、`wifi_config.py` 放在开发板同一目录中，确保该目录可以导入模块。运行 `避障无线预览.py`，不要同时运行其他摄像头脚本。
4. 程序先连接Wi-Fi，再初始化摄像头并检查JPEG压缩。成功后终端输出 `K230 preview: http://<实际IP>:8080/`。电脑浏览器打开输出的地址。
5. 要脱离USB运行，可将入口脚本保存为开发板 `main.py`，辅助模块也放在同目录。若已有main.py，先备份；调试时可以先保留USB供电。不要把USB启动的脚本正在运行时直接断开IDE当作已配置开机运行。

首次上传后，监看画面和调整参数通过Wi-Fi完成，不需要无线IDE或电脑额外安装库。

## 页面操作

只检测画面下方2/3：640×480下ROI为(0,160,640,320)，上方y=0～159保留显示但不参与识别。坐标仍以完整画面左上角为原点。物块跨越分界线时，只统计下方区域内的部分。

- 修改L/A/B的最小、最大值和“最小黑色像素数”，点击“应用参数”，下一次画面请求使用新参数，并重新累计确认帧。
- LAB范围：L为0～100，A/B为-128～127；每个最小值不得大于最大值。像素数为1～307200。
- 页面显示最大有效黑色物块的中心、包围框底部行、黑色像素数，以及候选/连续确认状态。3个处理帧中心稳定后确认；底部行不是经过标定的地面坐标。
- 参数只保存在内存里，重启后恢复默认。页面下方显示BLACK_THRESHOLD和MIN_PIXELS，调好后可复制到有线预览脚本；无线脚本默认值在obstacle_web.py的DEFAULT_CONFIG中。
- “暂停画面”暂停浏览器取帧。这个独立测试只在收到画面请求时做检测，不是后台持续运行的停车系统。
- 画面按单帧JPEG刷新，每帧收到后等待200ms再请求下一帧，实际刷新率取决于压缩耗时和Wi-Fi。单客户端调试即可。

## 故障排查

- Wi-Fi超时：核对账号、密码、频段和热点设置。密码为空只适用于开放网络。
- 页面打不开：使用终端打印的实际IP和8080端口；确认两端同一局域网且没有客户端隔离。不要把示例IP直接当作自己的地址。
- `ImportError`、压缩接口报错或JPEG检查失败：通过USB运行本目录的 `k230_debug_info.py`，保存终端输出和完整异常。不同出厂固件的接口可能不同；不要先为此刷写未知镜像。
- `MemoryError`或画面太慢：先把JPEG_QUALITY从50降低到35，关闭多余摄像头脚本和浏览器标签页。
- 调参后识别过多：提高最小像素数、收窄LAB范围；用比赛地面、灯光和阴影实测。像素数最大不保证物体最近。

该页面仅提供画面和阈值调试，不提供无线上传代码或运行/停止程序。代码已进行离线逻辑和网络收发测试；亚博板上的Wi-Fi、JPEG接口、耗时和识别效果仍需实测。

接口依据：[亚博Wi-Fi例程](https://www.yahboom.net/public/upload/upload-html/1747308652/1.%20Wireless%20network%20connection.html)、[CanMV图像压缩API](https://www.kendryte.com/k230_canmv/en/v1.3/api/openmv/image.html)、[官方HTTP JPEG示例中的非阻塞收发](https://github.com/kendryte/canmv_k230/blob/canmv_k230/resources/examples/02-Media/mjpeg_web_server.py)。本程序使用image.compressed，不依赖新固件的media.mjpeg。
