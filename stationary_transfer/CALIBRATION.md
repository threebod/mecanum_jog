# 标定和首次运行

未知参数没有用照片估算后写入。`firmware/config.c` 的数值只是旧工程参考值/占位值，`mechanics_ready=0`、`vision_ready=0`；`camera/settings.py` 的 `VISION_CALIBRATED=False`。开关打开也不能绕过非零矩阵、ROI、数值范围等检查。

## 1. 确认两轴基准和舵机换算

电机没有自动零点。选取可重复的人工基准，做实物刻度/定位标记：升降上方安全位置作为 Z=0，向下为正；平推以自定参考位置为 X=0，明确伸出正方向。禁止用程序撞端点找零。

记录实际行程和两端余量，填写 `axis_min/axis_max`、`positive_dir`、`steps_mm`。每次上电、异常停止、失步或人工移动后重新建立基准。两个轴与舵机姿态必须都清楚后，才使用：

```text
ZERO <实际X> <实际Z> <实际旋转指令角> <实际料盘指令角> <实际夹爪指令角>
```

这不是运动到零点的命令：两轴只建立软件坐标，但会使能电机并给舵机对应 PWM，舵机如果不在所声明位置会运动。不要把角度 0 当作所有舵机安全位置。这里没有通过视觉自动恢复未知关节状态。

原驱动 PWM 是 50 Hz、500—2500 us 对应配置的舵机全量程。默认夹爪/料盘 270°、旋转 360°来自旧源码，必须与实际舵机核对。夹爪指令角限定 30—80，用户确认 30 夹紧、80 张开；不沿用旧 PWM.c 中的减 1°/减 7.9°及旧开合角。

## 2. 单轴和单舵机小步试动

调试口 PA9/PA10，发送 STATUS 查询当前**指令估计位置**。用 `AXIS 0 value`、`AXIS 1 value` 每次不超过 2 mm，测量实际移动量和方向；`SERVO id angle` 每次不超过 5°。

确认：0 平推、1 升降；舵机 0 夹爪、1 料盘、2 旋转。反向时修改正方向，不同时改步数符号。步数系数、驱动细分、电机速度必须一起核对。

`ms_mm` 是各轴每毫米保守时间，加上 `settle_ms`；实测最长动作和负载后填写，不用轴长猜时间。舵机 `servo_ms_degree` 控制插值速度，加 100 ms 插值基时与 settle。程序没有编码器到位闭环。

## 3. 先确定防干涉姿态

确定 `safe_z`，确保夹起最高物料后横移/旋转不会撞料盘或台面。确定 `clear_x`，确保旋转料盘和机械手都不会碰到夹爪/物料。自动流程严格先到 safe_z，再到 clear_x，再旋转。

手动点动不执行这一整套路径，标定时自行按同样顺序操作。safe_z 定义为较小的 Z（更高），所有抓放 z 必须大于等于 safe_z。

## 4. 料盘与三个目的地

记录三个槽依次转到同一个取料窗口时的 `tray_angles[0..2]`。三槽不假设精确 120°，使用实测指令角。槽 1/2/3 只表示取料顺序，与颜色编号无关。

记录 `pick.x/theta/z`：先以固定物料调出可重复抓取路径。`z` 为夹紧高度，`x/theta` 为在 safe_z 上方观察并准备下降的姿态。

图示三环等间距时，中环作为局部原点，两端中心为 ±150 mm（总中心跨度 300 mm）；580 mm 为区域总长。此几何关系用于摆场和核对，不能直接填成平推行程，因为旋转、安装偏置和抓手偏置也参与定位。

在固定停车位置分别示教三个物理环的 `place[0/1/2].x/theta/z`。**place[0] 对应环上数字 1，不是图像最左侧。** 每个槽和目标颜色由 START 命令定义。第一版三个目标均应为空，不能用它码垛。

## 5. 顶部相机画面和颜色

把 camera 目录全部文件放到 MaixCAM2 同一个目录。先单独运行 `标定预览.py`，查看真实取景、六色中心和宽高；不要同时启动两个占用摄像头的程序。

采用 320×240；需要更改分辨率时须同步更改主控 ROI、协议坐标校验和全部标定值。最终固定补光、曝光/白平衡条件后调 LAB。补光默认关闭，确认灯向下才开启。蓝/浅蓝和黑色阴影须单独测试。

填写 `settings.py` 的 `SIZE_BOUNDS`：

- 模式 1：取料观察姿态下，物料可接受的像素宽高范围。
- 模式 3：夹紧并抬到 safe_z、平推尚未收回时，已抬起物料的像素宽高范围。
- 模式 4：松爪、抬到 safe_z、平推到 clear_x 后，已放置物料的像素宽高范围。

格式是 `(min_w,max_w,min_h,max_h)`，None 代表禁止识别成功。阈值不是越宽越好；夹爪本身、料盘黑色结构及环线不能进入合格候选。

**模式 3 必须排除仍在料盘里的物料。** 选择能分辨抬起/未抬起的 ROI、预期位置和尺寸范围，分别做空夹与真夹测试。若两种状态在该视角下无法区分，就不能声称抓取成功，也不能仅打开开关强行使用自动模式。程序当前不会从二维颜色推测精确高度或夹持力。

## 6. 每个姿态的 ROI、锚点与修正矩阵

`View={x,y,w,h,u,v}`：前四项为检测区域，后两项为正确对准时目标的像素位置。`u/v` 不一定是 160/120，它是实际抓手 TCP 对应的目标锚点。

每个 WorkPose 有：

- `align`：在 safe_z、工作 x/theta 时的对准画面；取料看物料，放置看空环。
- `verify`：取料为抬起后画面；放置为抬升并收回平推后的画面。二者不能随意共用同一组数字。
- `correction[4]`：误差到平推/旋转小步修正的局部 2×2 矩阵，分别标定 pick 和三个 place。
- `align_slope[4]`：正确抓放点（夹爪 TCP 在作业平面的投影）随平推/旋转改变的像素斜率，顺序为 `du/dx, du/dtheta, dv/dx, dv/dtheta`。
- `verify_slope[4]`：验证画面预期物料中心的像素斜率，顺序同上。抬起观察和落位观察高度不同，须分别标定。

先标定动态锚点：在基准 x/theta 下，将标定物放在夹爪下降后应正确抓放的位置，再升到 safe_z 拍照记录该目标点 u/v；将某关节小幅改变后，重新把标定物放到新的正确抓放点并拍照。两次像素差除以关节增量，得到该关节的 anchor slope。可以用辅助标记测 TCP，但不要用夹爪外轮廓中心直接代替夹持中心。旋转采样时也必须采用实际随动相机。

运行时目标锚点为 `base_uv + align_slope × [当前x-基准x, 当前theta-基准theta]`。因此**平推不带动相机、物料图像位置不变时仍可对准**：改变的是夹爪投影目标位置，不是强迫静止物料移到固定画面中心。

然后标定纠偏矩阵：这一次固定标定物不动，在基准姿态记录 `(u0,v0)`；单独将平推增加 Δx 记录 `(ux,vx)`，恢复基准；单独将旋转增加 Δtheta 记录 `(ut,vt)`，恢复基准。工具从目标像素导数中减去已标定的 anchor slope，计算误差导数的负逆矩阵：

```powershell
python tools/jacobian.py --base u0 v0 --x-sample ux vx --dx 1 --theta-sample ut vt --dtheta 1 --anchor-slope du_dx du_dt dv_dx dv_dt
```

输出矩阵供 `q += correction * (observed-dynamic_anchor)` 使用。这里只适用于该姿态附近；先做一小步，确认误差缩小再启用自动。默认每步最多 1 mm/1°、累计最多 8 mm/8°；要扩大范围需重新评估标定和环号误关联。若矩阵病态，程序工具拒绝输出，应调整观察姿态。

verify_slope 标定对象是**验证画面预期中心**：抓取验证使用夹持并抬起后的物料；放置验证使用已正确放在固定环上的物料。放置验证的 X 基准为 clear_x，其它基准取对应 WorkPose；取料验证的 X 基准为 pick.x。此方法是局部标定，并非实时识别夹爪轮廓；夹爪能看见用于人工标定检查，代码不声称已实现通用夹爪检测模型。

圆环检测至少要求三个相互分离的半径，局部 ROI 内若出现多个可匹配候选则拒绝。环线太大、斜视或只看见一部分时调相机姿态/距离及检测半径，不能通过放宽到“任何圆都可以”解决。

## 7. 不运动的通信核对

运行 `顶部搬运摄像头.py`。主控发送：

```text
SNAP 1 1 1
SNAP 2 1 1
```

相机显示当前模式、目标颜色/环和 ROI。主控输出 VISION u/v/quality/w/h；相机开关仍未开启时 flags=0 是预期行为。模式 1/3/4 在 SIZE_BOUNDS 为 None 时没有候选；先用预览设置范围。空帧、错误颜色、遮挡、重复物料应返回未确认；断开相机不应触发动作。

## 8. 开启自动与首轮验收

完成以上标定，检查 config 所有坐标和矩阵，再将 mechanics_ready、vision_ready 设为 1；相机 VISION_CALIBRATED 改为 True。重新编译/部署。不要只改三个开关而保留 POSE 宏中的全零矩阵；程序会拒绝。

每轮人工放好三个物料、清空三个目标环，固定停车姿态，人工确认基准并 ZERO。用 STATUS 等待 busy=0，再发送对应 START。例如槽内依次为红、黑、浅蓝且分别去环 1、2、3：`START 1 1 5 2 6 3`。

首先验证第一个物料，必要时用 PC9 或 STOP 中断；检查空夹、物料倾倒、相机遮挡、串口断开时是否确实停止且不虚增 placed。随后验证完整三槽流程。放置后的像素验证只是工程判据，应实测圆环内的实际毫米偏差。

配置目前保存在源文件，重新编译保存；不是 Flash 在线自动存储。ZERO 在 RAM 中，断电丢失，符合人工基准必须重新确认的设计。
