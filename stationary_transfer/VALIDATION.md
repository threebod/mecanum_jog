# 本机验证记录

验证日期：2026-09-16。所有验证为离线执行，没有连接、烧录或驱动实车。

## ARM 构建

- 编译器：本机 ARM GNU GCC 13.3.1，Cortex-M4，硬浮点，C99。
- 命令：`python tools/build.py`。
- 结果：成功，无编译/链接警告；生成 ELF、HEX、BIN 和 MAP。
- 最终大小：text 36528 字节、data 468 字节、bss（含链接预留堆栈）11412 字节。
- 默认机械/视觉标定开关为关闭，自动 START 会拒绝；上电 PWM 为零脉宽，不运行自动动作。
- Keil 项目的源文件路径已逐项检查存在；未用 Keil 实际构建，因此不能宣称 Keil 构建已验证。

## C 状态机与协议

`python tools/test.py` 用主机 GCC 以 `-Wall -Wextra -Werror` 编译便携逻辑与硬件 mock。

已通过：

- CRC 标准向量、30 个字节逐位扰动后的拒绝和下一帧恢复。
- 默认未标定拒绝、非法参数、NaN、错误 ROI、错误任务/无基准/硬件故障拒绝。
- 三槽取料到三个目标的完整状态流程；料盘只能在安全高度、收回位置且无持料时旋转。
- 重复帧不重复推进；错误 token/mode 不接受；过期观测与通信超时中止。
- 多次视觉失败中止；ROI 外坐标、验证位置偏离中止。
- 对准累计移动量超限中止；修正后必须获取新观测。
- 固定物料像素、平推仅改变 TCP 图像投影时可收敛。
- 停止后不继续发运动动作，不自动释放仍可能夹持的物料。

## Python 相机逻辑

7 个 unittest 全部通过：CRC/坏帧、分片粘包与噪声、请求范围、连续稳定窗、候选歧义、圆环中心按均值排序/不同半径筛选、先过滤色块再选择。

C 与 Python 的完整二进制帧交叉一致性通过。camera 目录 Python 语法编译通过。
