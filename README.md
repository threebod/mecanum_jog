# 麦克纳姆轮串口点动测试例程

已加入地图两轮底盘路线、指定安全航点移动和 IMU 闭环旋转，支持蓝牙 `route auto 1|2 [rpm]` 连续跑完整路线、`route step 1|2 [rpm]` 逐点测试、`nav init 1|2` 初始化估计位置、`nav goto X Y [rpm]` 移动到安全航点、`turn L|R 90` 单独旋转和 `!` 急停。启动运动前先发 `arm`。首次使用请阅读 [ROUTE_TEST.md](ROUTE_TEST.md)。路线和导航位置均为速度积分估计，尚未接入地面定位、随机避障、扫码及抓取流程。

已增加同步距离测试、IMU 航向保持、单轮验向和四轮 CAN 查询。完整新增命令、接线及落地测试步骤见 [STRAIGHT_TEST.md](STRAIGHT_TEST.md)。原有命令保留；新版本运动期间会拒绝叠加运动命令，等待测试窗口结束或先停车。

本例程用于架空状态下检查 1～4 号麦轮电机的编号、方向和四轮联动。工程复用 `yyb_stm32` 的 STM32F407ZG 标准外设库、CAN 和 Emm_V5 驱动，不会修改参考工程。

## 硬件与通信

- 主控：STM32F407ZG，系统时钟 168 MHz
- 电机总线：CAN1，PA11(RX)、PA12(TX)，500 kbit/s
- 蓝牙命令串口：UART5，PC12(TX)、PD2(RX)，115200、8N1
- 麦轮电机地址：1、2、3、4；辅助机构诊断地址：5、6
- 舵机 2/3/4：PA1/PA2/PA3，对应 TIM2_CH2/CH3/CH4

HC-05 与核心板交叉连接并共地：

| HC-05 | STM32F407ZG |
| --- | --- |
| TXD | PD2 / UART5_RX |
| RXD | PC12 / UART5_TX |
| GND | GND |

HC-05 数据串口应配置为 115200、1 停止位、无校验，常见完整 AT 固件对应 `AT+UART=115200,0,0`。模块 RXD 必须使用 3.3 V 逻辑电平；若底板没有输入分压，不要输入 5 V 串口电平。

> 软件停止不能替代硬件急停。首次运行必须架空四个轮子，确认人员可以立即断开电机电源，并且不要直接运行完整整车流程。

## 使用方法

使用 Keil MDK 打开 `MecanumJog.uvprojx`，通过有线下载器编译并下载。配对 HC-05 后，在电脑或手机上打开对应的蓝牙串口。命令除 `!` 外均以回车或换行结束：

```text
arm       授权下一次运动命令，执行一次后自动取消授权
disable   停止并失能 1～6 号电机，无需 arm
motor N D 5/6号电机按方向0/1短点动，必须先 arm
cancheck N 查询1～6号电机CAN状态并打印原始回包，无需 arm
servo N A 将舵机 N 移到电气角度 A，无需 arm
W / w     前进点动
S / s     后退点动
A / a     左移点动
D / d     右移点动
X / x     停止 1～6 号电机和舵机缓动，并取消授权
stop      停止 1～6 号电机和舵机缓动，并取消授权
!         无需回车，立即请求电机与舵机缓动紧急停止
help      显示命令帮助
nav init 1|2       以对应启停区初始化估计位置，要求空闲且 IMU 新鲜
nav goto X Y [rpm] 移动到安全航点，速度10～120 RPM，默认60，必须先arm
nav status         查询导航有效性、估计位置和目标
```

`nav goto` 只接受 `map_navigation.h` 中的十个安全航点，不接受任意坐标。上位机地图点击会吸附到最近航点。导航运行期间约每 200 ms 输出一次 `NAV POS`；正常完成输出 `NAV DONE`。`stop`、`!`、心跳超时、CAN/IMU 故障以及其他手动底盘动作都会使估计位置失效，之后必须把车放回启停区并重新执行 `nav init 1|2`。

Qt 上位机选择 `mecanum_jog 文本协议` 后会每 250 ms 静默发送内部命令 `hb`。
固件收到首个 `hb` 后启用通信看门狗；若后续 1000 ms 未收到心跳，会停止 1～6 号
电机、停止舵机缓动并取消授权和路线，然后输出
`ERR: host heartbeat timeout; stopped`。从未发送过 `hb` 的手机或普通串口会话保持原行为。
该看门狗只能请求软件停车，不能替代断电急停。

舵机 2、3 的角度范围为 0～270°，舵机 4 为 0～360°。例如：

```text
servo 2 45
servo 3 90
servo 4 180
```

复位后 PA1、PA2、PA3 均不输出 PWM。每个舵机的第一条有效命令会直接建立该通道的软件当前位置；同一通道后续命令以 30°/秒缓动，并在到达后返回 `DONE servo=<编号> angle=<角度>`。`X`、`stop` 和 `!` 会取消正在进行的舵机缓动，并保持当前位置的 PWM 输出。

上电后发送一次授权再前进；运动命令会自动使能所需驱动器：

```text
arm
W
```

W/S/A/D 会消耗一次授权；再次发送 `W` 会被拒绝，必须重新发送 `arm`。测试结束可直接发送 `disable`。默认点动参数为 30 RPM、加速度 50、160 脉冲，四个电机使用同步位置模式启动。`line` 仅接受100、200、300、400或500 mm，`line/straight` 转速范围为10～120 RPM。

若要单独测试5号或6号辅助电机：

```text
arm
motor 5 0
arm
motor 6 1
stop
```

5、6号电机使用相同的保守点动速度、加速度和脉冲数，采用参考工程中单电机位置控制的立即启动方式，不发送同步启动帧。6号电机在参考工程中用于平推机构，首次测试必须确认机械限位并从安全位置开始。`X`、`stop` 和 `!` 均会停止1～6号电机。

若电机不转，先发送：

```text
cancheck 6
```

收到驱动器回包时，串口输出 `CAN RX motor N` 以及扩展帧 ID、DLC 和原始数据；300 ms 内没有回包时，输出 `ERR: motor N no CAN reply` 以及 STM32 CAN 的 `ESR/TSR` 寄存器值。`TX queued` 只表示固件已把运动命令交给 CAN 外设，不表示驱动器已经执行。

## 方向映射

| 车体方向 | 1号 | 2号 | 3号 | 4号 |
| --- | --- | --- | --- | --- |
| 前进 W | 反 | 正 | 正 | 反 |
| 后退 S | 正 | 反 | 反 | 正 |
| 左移 A | 反 | 反 | 正 | 正 |
| 右移 D | 正 | 正 | 反 | 反 |

这里的“正/反”对应 Emm_V5 的方向位 0/1 组合，映射与 `yyb_stm32/can_ZDT/yyb_move.c` 一致。

## 首次检查顺序

1. 只给主控和 CAN 收发器供电，确认串口出现就绪提示。
2. 接通电机动力后确认上电不会自动运动。
3. 未发送 `arm` 时发送 W/S/A/D 和 `motor 5 0`，确认均返回错误且电机不动。
4. 依次发送 `arm` 加 W、S、A、D，每次只观察一次低速点动并确认自动使能。
5. 分别发送 `cancheck 5`、`cancheck 6`，确认辅助电机地址和回包。
6. 舵机首次测试应卸除连杆，并从接近当前实际位置的小角度开始；舵机必须使用合适的外部电源并与主控共地。
7. 运动期间发送 `!`，确认 1～6 号电机停止且舵机停止继续缓动；测试结束发送 `disable`。
8. 若实际方向与表格不符，先核对电机地址、安装方向和驱动器方向配置，不要直接修改整车参考工程。

## 自动合约检查

在工作区根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File mecanum_jog-main\mecanum_jog-main\tests\test_contract.ps1
```

该检查验证工程目标、共享源码路径、串口参数和方向表；它不能替代 Keil 编译或实机测试。

PC12/PD2 对应 UART5，只用于程序运行后的蓝牙命令通信。STM32F407 内置 ROM Bootloader 不支持 UART5，不要通过该 HC-05 连接烧录固件；烧录仍使用调试器或 PA9/PA10 上的有线下载连接。
