# 麦克纳姆轮串口点动测试例程

放置松爪后，升降抬升、水平收回和空载云台转回合为同一姿态动作，不再先单独抬升。粗加工第三件放置后的返回动作同样合并。两轮粗加工回收最后一件到料盘并完成松爪后，底盘立即继续路线，同时仅将升降轴抬到0；水平轴保持各轮料盘放料位置-450/-470，云台保持132°，直到暂存区再展开到观察姿态（水平-770、升降0、云台272°）。

## 硬件与通信

- 主控：STM32F407ZG，系统时钟 168 MHz
- 电机总线：CAN1，PA11(RX)、PA12(TX)，500 kbit/s
- 蓝牙命令串口：UART5，PC12(TX)、PD2(RX)，115200、8N1
- 淘晶驰 T1 串口屏：USART6，PC6(TX) 接屏幕 RX、PC7(RX) 接屏幕 TX，115200、8N1，3.3 V TTL 并共地
- 麦轮电机地址：1、2、3、4；辅助机构诊断地址：5、6
- 舵机 2/3/4：PA1/PA2/PA3，对应 TIM2_CH2/CH3/CH4

HC-05 与核心板交叉连接并共地：

| HC-05 | STM32F407ZG |
| --- | --- |
| TXD | PD2 / UART5_RX |
| RXD | PC12 / UART5_TX |
| GND | GND |

HC-05 数据串口应配置为 115200、1 停止位、无校验，常见完整 AT 固件对应 `AT+UART=115200,0,0`。模块 RXD 必须使用 3.3 V 逻辑电平；若底板没有输入分压，不要输入 5 V 串口电平。

> 软件停止不能替代硬件急停。首次运行必须架空四个轮子，确认人员可以立即断开电机电源，并且不要直接运行完整整车流程。

## 使用方法

使用 Keil MDK 打开 `MecanumJog.uvprojx`，通过有线下载器编译并下载。配对 HC-05 后，在电脑或手机上打开对应的蓝牙串口。命令除 `!` 外均以回车或换行结束：

上位机“路线编辑”页使用新增的 `move W|S|A|D 距离mm RPM` 相对移动指令，
距离 1～2400 mm、速度 10～250 RPM，横移受 `route tune` 的横移速度上限限制。
方向相对当前车头，保持启动时 IMU 航向，沿用现有前后／横移比例进行速度积分估算。
启动与完成分别反馈 `MOVE RUN dir=... distance_mm=... rpm=...` 和
`MOVE DONE dir=... distance_mm=...`；完成只停止底盘，不清除机构初始化。
单独转向成功也保留机构初始化，但会使旧地图导航位置无效。
`mech status` 增加 `MECH SERVOS gripper_mdeg=... platform_mdeg=... turret_mdeg=... moving=...`，
供路线动作组核对初始状态。故障、手动停止及心跳超时仍停止并清理全局运动状态。

```text

S / s     后退点动
```

`mech pose` 和 `auxmove` 对 5/6 号升降、平推电机的可设上限为 1200 RPM、加速度参数 200，与上位机动作录入和定距调试界面一致。现有自动取放动作表仍保留原速度；高转速应先在架空、可急停条件下分轴测试，实际到位仍需人工核对。

`nav goto` 接受地图范围内、车体按 300×300 mm 计算后仍满足净空的任意整数坐标。规划器会从当前估计位置接入静态安全航点图，并以水平或垂直安全线段到达目标；障碍区、边界净空不足或无法通过安全通道到达的坐标会返回 `ERR NAV:`。地图点击仍可吸附既有安全航点，也可在上位机输入精确坐标。导航运行期间约每 200 ms 输出一次 `NAV POS`；正常完成输出 `NAV DONE`。`stop`、`!`、心跳超时、CAN/IMU 故障以及其他手动底盘动作都会使估计位置失效，之后必须把车放回启停区并重新执行 `nav init 1|2`。

`route start`、`route step`、`route auto`、`route rawpick`、`route mission`及PC9启动分别使用 `route_plan.h` 的 `routeDistanceZone1` 和 `routeDistanceZone2` 两套完整距离表：每段仅保存向上/向右的有符号距离、出发朝向、到达朝向和工位事件，不使用全图航点。距离按下发转速、时间和前进/横移标定比例估算；IMU负责朝向，视觉仍负责工位局部对准。上位机显示每段已走/目标距离，不用距离消息更新地图位置。两套表各自包含完整20段的距离、朝向和工位事件，`routeDistanceLeg` 只按起点选择对应表，不再叠加共用表或起点修正；修改某套的距离和转向只影响该套。底层运动控制与取放流程共用。独立的人工 `nav goto` 功能仍使用地图导航，与两轮距离任务分开。

`route auto 1|2 [rpm]` 是仅控制底盘的完整跑图命令，依次经过二维码区、第一轮原料/粗加工/暂存、第二轮原料/粗加工/暂存并返回对应启停区。按固定的方向、距离和朝向逐段执行，每段从0累计已走距离，不读取或重置全图X/Y。运行时约每 200 ms 输出 `ROUTE DIST`（段号、地图方向、目标距离、已走距离、朝向和状态），到达作业点输出 `ROUTE STAGE`，结束输出 `ROUTE DONE mode=DISTANCE`；它不会执行扫码、抓取或其他机械动作。

路线与导航按车头朝向判断车体横移并应用横移转速上限：车头朝上/下时沿地图X移动属于横移，朝左/右时沿地图Y移动属于横移。两轮原料区到粗加工区均先转为车头朝下，向前直行到站后转为车头朝右；两轮完整取放任务均将取料微调的反向补偿与沿地图向右退出50毫米合成一次移动。该段直行使用前进比例及请求速度，不受横移上限约束；其他横移默认上限150 RPM，低于上限的请求速度保持原值。

`route rawpick 1|2 [rpm]` 是原料区联调命令。出发前确认机构实际位于水平0、升降0、转台65°、夹爪闭合35°、平台1槽，并执行 `mech init 0 0 650`；核对物料对准方向和抓取锚点后发送 `arm`、`vision scale material 640 673`，再发送 `arm` 和路线命令，也可在上位机“场地定位”页点击“路线取料联调（RAW_1 三件）”。未应用物料比例时路线拒绝启动，比例仅保存在 RAM。路线到达 `RAW_1`、完成转向后停车；依次抓取绿(4)、黄(2)、浅蓝(6)，分别放入平台1、2、3槽。每件先将水平轴收至-770、转台到272°并保持升降0，再同时开始相机识别与升降轴下降500（50 mm）；升降运动结束并重新确认目标后才夹取，相机按v1.0.9采用附件六色阈值及原面积范围，取最大色块，取消物料质量及贴边筛选；连续10个有效帧且各轴中心波动不超过8像素即稳定，无最低500ms等待，回传这10帧中心中位数及实际颜色。每轮先用任意颜色1～6中面积最大的物料校准，首次及后续均以画面X轴±14像素为范围，Y轴换算本次夹取的水平轴补偿；X超限时只按原X映射修正底盘，停稳300ms后重新请求复检。首次对准完成后才等待绿色，重新确认连续10帧静止且X轴进入范围，一轮合格结果即可夹取；后两件依次等待黄色和浅蓝色，同样按X轴±14像素确认，X超限则再次校准；每件动作完成后才标记该颜色已收集。目标移动或识别不稳定时继续等待，不调整车辆或执行夹取；通信超时、机构或IMU/CAN故障会停止流程。第三件动作结束输出 `ROUTE RAWPICK state=DONE color=0 slot=0`，车辆仍停在 `RAW_1`，人工检查后发送 `route next` 或点击上位机“确认并继续路线”才继续；三件未完成时拒绝继续。`stop`、`!` 或故障后不能直接续行，须核实机构位置并重新初始化。对准只依据物料中心，不验证夹持结果；每段已走距离仍按转速和时间估计，没有地面距离反馈。

## 上位机任务码

任务码为 `CCC+PPP+CCC+PPP`，严格四组三位数。第一、三组为两批的颜色和搬运顺序；第二组为第一批在粗加工区和暂存区的位置，第四组仅为第二批在粗加工区的位置，每组必须为1、2、3的排列。第二批暂存按第一层颜色位置同色码垛，不使用第四组；两批颜色须能一一匹配，否则在码垛前停止并报告 `mission_stack_colors`。颜色：红1、黄2、蓝3、绿4、黑5、浅蓝6。圆环1的角度最大（306.5°），其次是圆环2（265.7°）、圆环3（232°）。

例如 `156+123+516+231`：第一批红、黑、浅蓝依次进入平台槽1/2/3，粗加工放置、回收及第一层暂存均按环1→2→3执行；第二批黑、红、浅蓝依次进入槽1/2/3，粗加工放置和回收均按环2→3→1执行；第二层暂存按黑、红、浅蓝顺序，依次码垛到同色的环2→1→3。所有阶段均依次选择槽1→2→3。暂存第二批使用第二层的650深度。粗加工回收保持原槽与物料对应关系。

上位机“场地定位”页填写任务码后点击“开始两轮完整取放”，会先发送 `task 156+123+516+231`，仅在收到相同任务码的 `TASK SET code=156+123+516+231` 后继续舵机、视觉比例和路线启动准备。非法格式或运行中修改返回 `ERR TASK`，不覆盖当前有效任务。任务只存在RAM，启动时清除上位机任务的有效标志，但保留本次收到的合法扫码缓存；到扫码点时采用并消耗缓存，若无缓存则等待新合法扫码码后继续。扫码确认覆盖预先下发的任务，不使用上位机任务作为扫码失败时的后备。

## PC9按键启动完整任务

PC9配置为GPIO输入、内部上拉；按键一端接PC9，另一端接主控GND。按下为低电平，按下和松开均进行30 ms消抖。短按不足1秒并松开启动启停区1；长按满1秒立即启动启停区2，继续长按和随后的松开不重复启动。上电时按键已经接地不会启动，须先松开再按；运行中的按键事件不会排队到任务结束后执行。

上电后无需连接上位机：水平/升降轴按用户确认的物理零位初始化为0，云台指令65°、夹爪35°、平台26°，物料和圆环2比例采用前后640、左右673，默认200 RPM。舵机指令运动结束后按PC9即可启动完整任务，到扫码点等待四组任务码（例如 `156+123+516+231`）。IMU必须新鲜、CAN必须健康，按键仅授权本次任务启动。

终端 `arm`、`route button <rpm>` 仍可重新准备PC9并选择10～250 RPM速度；上位机仍可覆盖视觉比例。PC9准备及按键启动任务无需主机心跳；上位机直接发送 `route mission` 启动的任务仍保留现有心跳保护。停止、失能、急停、CAN故障会取消准备，运行中IMU/CAN/视觉通信与动作故障保护保持。任务结束或中止后不会自动重新准备；须核实实际姿态、恢复零位后重新准备或重新上电，禁止原地盲目续跑。

软件检查已覆盖GPIO上拉设置、消抖、短／长按分区、启动前无底盘使能、长按不重启、上电按住、启动状态变化和毫秒计时回绕；接线、按键输入电平及两个启停区的实车完整流程尚未验证。

## 视觉微调

取料区坐标校验：画面X偏差 `du=u-160` 保持现有±14像素容差，范围内底盘不动，超限只沿原X映射修正底盘并停稳复检。画面Y偏差 `dv=v-120` 不再驱动底盘，按物料Y比例 `R` 换算水平轴：`补偿(mm)=-R×dv/1000`（R为毫米/像素乘1000），`夹取目标(0.1mm)=-200+round(-R×dv/100)`。例如R=673、dv=+35时目标为-436（-43.6mm），画面偏下减少伸出。只使用升降结束后、当前指定颜色的最新稳定样本；首次任意颜色对齐不执行抓取补偿。补偿应用于夹取伸出、夹紧后抬升，以及抬升后转向平台时保持的水平位置；平台放回坐标和末尾复位保持原值，各件独立计算。目标超过水平轴-122.0～65.0mm范围时输出 `PICK_HORIZONTAL_RANGE` 并停止，不夹取、不截断位移。日志 `VISION PICK OFFSET` 输出dv、补偿及目标（单位0.1mm）。仅两轮任务及route rawpick的取料区生效，单件固定夹取测试、普通视觉对准、圆环和暂存流程保持原逻辑。方向按用户确认，实机效果仍需低速验证。

上位机也支持物料比例自动标定：在“视觉微调”选择物料及固定颜色，先将机构置于实际取料观察姿态，保持该颜色的单个物料静止可见，确认各方向20 mm净空后点击“自动标定物料比例”。机构姿态须人工准备，程序不夹取；前后、左右各往返20 mm（15 RPM），每步停稳300 ms。新增 `vision sample material COLOR ID` 只读采样，回包包含样本ID和颜色，稳定性及指定颜色检查通过才采样，质量值仅作诊断。比例经主控确认后独立应用，完整任务不会覆盖成默认物料比例；断电恢复默认值。此功能需要配套更新主控固件，摄像头程序无需因本功能更新，尚未实机验证。

舵机 2、3 的角度范围为 0～272°，舵机 4 为 0～360°。例如：

```text
servo 2 45
servo 3 90 1800
servo 4 180 1800
```

第三个参数为可选速度，单位是0.1°/s，范围10～1800；省略时使用1800，即180°/s。上电后 PA1（夹爪）输出35°指令、PA3（云台）输出65°指令，PA2（平台）在收到有效指令前不输出PWM。每个舵机的第一条有效命令会直接建立该通道的软件当前位置；同一通道后续命令按指定速度缓动，并在到达后返回 `DONE servo=<编号> angle=<角度>`。`X`、`stop` 和 `!` 会取消正在进行的舵机缓动，并保持当前位置的 PWM 输出。

云台通道4的后续运动采用五次曲线缓启动、缓停止，速度参数表示指令峰值速度；通道2、3保持匀速更新。带料云台运动时间按 `1.875 × 角度差 / 峰值速度` 计算，空载按 `角度差 / 200°/s` 计算并向上取整到20 ms，例如带料90°、180°/s需要940 ms。完成消息仅表示指令轨迹结束，未读取舵机实际位置。

取料、粗加工放置与回收、暂存放置及观察姿态的水平轴目标速度统一500 RPM，加速度参数200（按当前驱动公式约357 RPM/s）；短行程可能达不到目标速度，须实测机械净空、振动和抓取稳定性。升降轴在取料、放置、回收、暂存及观察姿态中统一为2000 RPM、加速度参数240，与参考工程一致。动作之间没有统一间隔：姿态动作在水平轴有位移时为该轴估算时间增加50 ms余量，再根据水平、升降、云台三者中最长的估算运动时间推进，不等待5、6号电机到位回包，不追加步进轴500 ms或云台100 ms余量；云台PWM缓停轨迹尚未结束时仍等待轨迹完成。没有电机到位反馈也会在估算时间结束后继续，`MECH POS` 和 `MECH DONE` 均不能证明步进轴实际到位。急停、心跳超时和CAN发送故障仍会停车并使机构位置失效。动作表的 `waitMs` 在完成后再追加，0表示没有追加等待；取料、粗加工和暂存流程均无额外固定等待，原暂存夹紧前500 ms等待保持移除。夹爪开合速度统一270°/s，仍须完成指令运动，平台180°/s转动与机构并行，但下降到平台取放前须等待平台指令转动完成。取料、暂存及观察姿态中原120°/s的舵机速度均提高到180°/s。4号云台在空载时取消缓启动、缓停止，以200°/s匀速转动；夹爪夹紧后按可能带料处理，恢复动作表原有的缓启动、缓停止轨迹，张开到90°后恢复空载模式。负载状态依据夹爪指令推断，上电闭合初始化按空载处理，没有夹持传感器。空载运动仍等待指令轨迹完成，姿态等待时间按空载转动与步进轴中最长时间计算；夹爪和平台保持匀速。所有舵机完成判断均为指令执行状态，没有实物位置反馈。`cancheck` 和单轴 `auxmove` 原有状态查询行为保持不变。

## 首次检查顺序

1. 只给主控和 CAN 收发器供电，确认串口出现就绪提示。
2. 上电云台会收到65°PWM指令、夹爪会收到35°闭合指令，先确认该角度的机械净空；步进电机不会自动运动。首次启用PWM无法知道舵机实际角度，不保证从实际位置缓动。
3. 未发送 `arm` 时发送 W/S/A/D 和 `motor 5 0`，确认均返回错误且电机不动。
4. 依次发送 `arm` 加 W、S、A、D，每次只观察一次低速点动并确认自动使能。
5. 分别发送 `cancheck 5`、`cancheck 6`，确认辅助电机地址和回包。
6. 舵机首次测试应卸除连杆，并从接近当前实际位置的小角度开始；舵机必须使用合适的外部电源并与主控共地。
7. 运动期间发送 `!`，确认 1～6 号电机停止且舵机停止继续缓动；测试结束发送 `disable`。
8. 若实际方向与表格不符，先核对电机地址、安装方向和驱动器方向配置，不要直接修改整车参考工程。
