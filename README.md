# 麦克纳姆轮串口点动测试例程

本例程用于架空状态下检查 1～4 号麦轮电机的编号、方向和四轮联动。工程复用 `yyb_stm32` 的 STM32F407ZG 标准外设库、CAN 和 Emm_V5 驱动，不会修改参考工程。

## 硬件与通信

- 主控：STM32F407ZG，系统时钟 168 MHz
- 电机总线：CAN1，PA11(RX)、PA12(TX)，500 kbit/s
- 蓝牙命令串口：UART5，PC12(TX)、PD2(RX)，115200、8N1
- 麦轮电机地址：1、2、3、4；单电机诊断地址：5

HC-05 与核心板交叉连接并共地：

| HC-05 | STM32F407ZG |
| --- | --- |
| TXD | PD2 / UART5_RX |
| RXD | PC12 / UART5_TX |
| GND | GND |

HC-05 数据串口应配置为 115200、1 停止位、无校验，常见完整 AT 固件对应 `AT+UART=115200,0,0`。模块 RXD 必须使用 3.3 V 逻辑电平；若底板没有输入分压，不要输入 5 V 串口电平。

> 软件停止不能替代硬件急停。首次运行必须架空四个轮子，确认人员可以立即断开电机电源，并且不要直接运行完整整车流程。

## 使用方法

使用 Keil MDK 打开 `MecanumJog.uvprojx`，通过有线下载器编译并下载。配对 HC-05 后，在电脑或手机上打开对应的蓝牙串口。命令除 `!` 外均以回车或换行结束：

```text
arm       授权下一次 enable 或运动命令，执行一次后自动取消授权
enable    使能 1～4 号电机，必须先 arm
disable   失能 1～4 号电机并取消授权，无需 arm
enable5   使能 5 号诊断电机，必须先 arm
motor5 0  5 号电机按方向 0 点动，必须先 arm
motor5 1  5 号电机按方向 1 点动，必须先 arm
disable5  停止并失能 5 号电机，无需 arm
W / w     前进点动
S / s     后退点动
A / a     左移点动
D / d     右移点动
X / x     停止 1～4 号电机并取消授权
stop      停止 1～4 号电机并取消授权
!         无需回车，立即请求紧急停止
help      显示命令帮助
```

上电后先使能四个驱动器，再前进一次：

```text
arm
enable
arm
W
```

`enable` 和 W/S/A/D 都会消耗一次授权；再次发送 `W` 会被拒绝，必须重新发送 `arm`。测试结束可直接发送 `disable`。默认点动参数为 30 RPM、加速度 50、160 脉冲，四个电机使用同步位置模式启动。

若要先排除四轮同步问题，只测试 5 号电机：

```text
arm
enable5
arm
motor5 0
arm
motor5 1
disable5
```

5 号电机使用同样的速度、加速度和脉冲数，但采用参考工程中单电机位置控制的立即启动方式，不发送同步启动帧。`X`、`stop` 和 `!` 均会停止 1～5 号电机。

## 方向映射

| 车体方向 | 1号 | 2号 | 3号 | 4号 |
| --- | --- | --- | --- | --- |
| 前进 W | 反 | 正 | 正 | 反 |
| 后退 S | 正 | 反 | 反 | 正 |
| 左移 A | 反 | 反 | 正 | 正 |
| 右移 D | 正 | 正 | 反 | 反 |

这里的“正/反”对应 Emm_V5 的方向位 0/1 组合，映射与 `yyb_stm32/can_ZDT/yyb_move.c` 一致。

## 首次检查顺序

1. 只给主控和 CAN 收发器供电，确认串口出现就绪提示。
2. 接通电机动力后确认上电不会自动运动。
3. 未发送 `arm` 时发送 `enable` 和 W/S/A/D，确认均返回错误且电机不动。
4. 发送 `arm`、`enable`，确认 1～4 号驱动器进入使能状态且车轮不自行转动。
5. 依次发送 `arm` 加 W、S、A、D，每次只观察一次低速点动。
6. 运动期间发送 `!`，确认 1～4 号电机停止；测试结束发送 `disable`。
7. 若实际方向与表格不符，先核对电机地址、安装方向和驱动器方向配置，不要直接修改整车参考工程。

## 自动合约检查

在工作区根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File test\mecanum_jog\tests\test_contract.ps1
```

该检查验证工程目标、共享源码路径、串口参数和方向表；它不能替代 Keil 编译或实机测试。

PC12/PD2 对应 UART5，只用于程序运行后的蓝牙命令通信。STM32F407 内置 ROM Bootloader 不支持 UART5，不要通过该 HC-05 连接烧录固件；烧录仍使用调试器或 PA9/PA10 上的有线下载连接。
