# 当前两轮路线 JSON

这两个文件可在上位机“路线编辑”页通过“打开 JSON”加载。它们是人工识别衔接版，不是原固件完整自动流程的等价实现。

## 使用前提与差异

- 从对应启停区出发，车头朝地图上方；初始机构水平0、升降0、云台65°，夹爪张开70°，平台1槽26°。在动作录入页完成实际位置确认及初始化后，再开始路线。
- 固件原入口也允许云台270°和夹爪35°；本导出采用当前上位机任务入口的65°、70°准备状态，不兼容这些替代起始姿态。
- 使用编译默认底盘200 RPM、横移上限150 RPM、前后比例1.0、横移比例0.9，以及视觉比例640/673。未读取设备RAM或当前GUI调参值，运行前核对实际设置。
- 不限颜色对准、每件指定颜色确认，以及第二轮暂存按圆环2标定识别绿色物料，均用人工确认替代；这些确认步骤不会自动识别或调整车辆。人工调整仅平移，须保持本段车头方向。
- 人工确认期间其他运动页面被路线执行器锁定。不要尝试启动另一条路线或原料区联调；需要软件控制调整时，先停止当前路线，单独完成准备后从合适步骤重新测试。
- 动作序列和参数取自当前固件实际C数组，未采用可能过期的“动作组”目录JSON。每个内嵌动作组的initialState按该处实际入口姿态、夹爪和平台槽衔接填写。
- 固件中平台零等待转动可与机构动作并行；路线编辑器按动作到位顺序执行，故顺序和落点保留，但节拍与固件并行流程不同。
- 转向终态保留。180°步骤固定选择JSON中的左／右方向；原固件按实际IMU角差选择，正负180°边界时旋转方向可能不同。
- 二维码点保留1秒等待，沿用现有K230接收和显示，不按扫码结果调整取料顺序。视觉对准后不回退微调距离。
- 航段方向已经由地图坐标换算成当前车头坐标。例如第一次到原料区是地图向左，但车头已朝左，JSON为W前进980 mm（启停区1）或930 mm（启停区2）。
- 路线抵达偏移站点后按新的停车位置衔接后续原定相对距离，没有额外回到旧名义坐标的运动。
- JSON加载和软件校验不代表实机距离、净空或取放结果已经验证；本次没有烧录或驱动车辆。

## 来源

两份JSON均已通过上位机实际 `loadRouteSequence` 加载器。各含62个路线步骤、275个机构动作；23个内嵌动作组的入口姿态、夹爪和平台状态均已逐组检查衔接，首次取料距离、第二次取料补偿及最终车头朝向也已检查。本次没有修改上位机或固件功能代码。
